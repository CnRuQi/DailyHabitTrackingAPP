# 1 课题设计内容

## 1.1 课程设计基本功能描述

本项目开发了一款基于Android平台的**每日习惯追踪APP**，旨在帮助用户记录和管理日常习惯，培养良好的生活习惯。该应用采用Java语言开发，使用SQLite数据库进行数据存储，界面采用谷歌Material设计风格，具有现代化的视觉效果和流畅的交互体验。主要功能包括：

### 核心功能
- **用户注册与登录**：支持用户注册新账号，登录时可选择记住密码，使用本地偏好设置保存登录信息，实现用户数据隔离。
- **习惯管理**：支持添加、编辑、删除习惯记录，每条记录包含标题、描述、照片、日期和时间等信息。
- **拍照功能**：支持调用摄像头拍照或从相册选择图片，支持图片全屏预览。
- **列表展示**：使用列表视图以线性列表形式展示所有习惯，支持点击编辑和长按删除操作。

### 打卡与统计功能
- **每日打卡**：支持对每个习惯进行每日打卡，记录打卡日期，自动计算连续打卡天数。
- **完成进度**：首页显示今日完成进度条，直观展示完成情况。
- **日历视图**：首页集成月历组件，以网格形式展示当月打卡记录，已打卡日期以绿色高亮显示，当日以主题色标记。
- **数据统计**：个人中心页展示总习惯数、今日完成数、最长连续天数等统计数据。

### 筛选与搜索功能
- **状态筛选**：支持按状态筛选习惯（全部、未完成、已完成），使用分段按钮控件实现。
- **搜索功能**：支持按关键词搜索习惯，实时过滤列表内容。
- **滑动删除**：支持左右滑动删除习惯，删除后可点击"撤销"恢复，5秒后自动清除。

### 提醒与激励功能
- **每日提醒**：支持设置每日提醒时间，使用系统闹钟定时触发，通过系统通知提醒用户打卡。
- **成就徽章**：根据连续打卡天数解锁不同等级徽章（铜牌：7天、银牌：30天、金牌：100天），激励用户坚持打卡。

### 界面设计
- **双页面布局**：采用底部导航栏实现页面切换，包含"首页"和"我的"两个页面，支持页面切换动画。
- **莫奈配色**：采用莫奈浅色系配色方案，界面简洁美观，具有良好的用户体验。
- **动画效果**：添加布局加载动画和页面切换动画，提升交互流畅度。

## 1.3 数据库设计

本应用使用SQLite数据库，包含以下三张数据表：

### 表1 用户表（tb_user）

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|----------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 用户ID |
| username | TEXT | NOT NULL UNIQUE | 用户名 |
| password | TEXT | NOT NULL | 密码 |

### 表2 习惯表（tb_habit）

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|----------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 习惯ID |
| user_id | INTEGER | - | 用户ID（外键） |
| title | TEXT | NOT NULL | 习惯标题 |
| content | TEXT | - | 习惯描述 |
| imageuri | TEXT | - | 图片路径 |
| date | TEXT | - | 创建日期 |
| time | TEXT | - | 创建时间 |

### 表3 打卡记录表（tb_checkin）

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|----------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 记录ID |
| user_id | INTEGER | - | 用户ID（外键） |
| habit_id | INTEGER | - | 习惯ID（外键） |
| checkin_date | TEXT | - | 打卡日期（格式：yyyy-MM-dd） |

**数据库版本管理**：应用使用数据库帮助类进行版本管理，当前版本为4。通过升级方法实现平滑升级，包括添加完成状态字段、创建打卡记录表、添加用户ID字段等。

## 1.4 程序运行结果

### （1）登录页面

登录页面采用莫奈浅色系设计，包含用户名输入框、密码输入框、记住密码选项、登录按钮和注册入口。界面简洁美观，用户体验良好。登录成功后自动跳转到首页，记住密码功能使用本地偏好设置持久化存储。

### （2）注册页面

注册页面包含用户名、密码、确认密码三个输入框，支持验证两次密码是否一致，以及用户名是否已存在。注册成功后自动返回登录页面。

### （3）首页（习惯列表页面）

首页采用双页面布局设计，通过底部导航栏切换。首页包含以下核心组件：

- **日历视图**：顶部显示当月日历网格，已打卡日期以绿色高亮显示，当日以主题色标记，直观展示打卡记录。
- **完成进度条**：显示今日完成进度，格式为"✅ X/Y 已完成"，实时更新。
- **筛选控件**：使用分段按钮组实现，支持"全部"、"未完成"、"已完成"三种筛选模式。
- **搜索栏**：支持按关键词搜索习惯，实时过滤列表内容。
- **习惯列表**：使用列表视图展示习惯记录，每条记录显示标题、描述、日期、时间、图片和打卡状态。支持点击进入编辑页面，长按弹出删除确认对话框，左右滑动删除（带撤销功能）。
- **空状态**：当没有习惯时显示空状态提示，引导用户添加第一个习惯。

### （4）添加/编辑习惯页面

添加和编辑页面包含标题输入、内容输入、拍照按钮、相册选择按钮和图片预览。支持调用摄像头拍照或从相册选择图片，自动获取当前日期和时间。编辑页面支持修改已有习惯的所有信息。

### （5）我的（个人中心页面）

个人中心页面展示用户信息和统计数据，包含以下组件：

- **用户信息卡片**：显示用户头像、用户名和统计概览（总习惯数、总打卡次数）。
- **数据统计栏**：三个等宽卡片分别显示总习惯数、今日完成数、最长连续天数，数据实时更新。
- **成就徽章**：三个徽章（铜牌、银牌、金牌）根据连续打卡天数解锁，未解锁时显示灰色半透明状态，解锁后显示彩色状态并附带文字说明。
- **每日提醒**：支持开启/关闭每日提醒，设置提醒时间，使用系统闹钟定时触发通知。
- **退出登录**：点击后弹出确认对话框，确认后清除登录状态并跳转到登录页面。

### （6）通知提醒功能

应用支持每日定时提醒功能，用户可在个人中心开启提醒并设置时间。系统使用闹钟管理器设置精确闹钟，通过通知管理器发送通知，通知内容包含习惯打卡提醒，点击通知可直接打开应用。

## 2.2 课程设计心得

通过本次Android课程设计，我收获了很多实践经验和知识：

首先，我对Android应用开发有了更深入的理解。从项目搭建、界面设计、数据库操作到功能实现，每一个环节都让我对Android开发流程更加熟悉。特别是SQLite数据库的使用，让我掌握了本地数据存储的方法，以及如何通过版本管理实现数据库平滑升级。

其次，我学会了使用列表视图实现列表展示功能。列表视图是Android中非常重要的组件，通过自定义适配器和视图持有者，可以灵活地展示各种数据。在实现过程中，我掌握了点击事件、长按事件和滑动删除的处理方法，以及如何使用布局动画控制器实现列表加载动画。
